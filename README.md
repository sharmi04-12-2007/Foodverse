 🍴 FoodVerse – A Universe of Flavours

FoodVerse is a responsive frontend food delivery website developed using HTML, CSS and JavaScript.

The website allows users to explore food categories, search for food items, view restaurants, add food to a cart and simulate placing an order.

 🌐 Project Overview

FoodVerse provides a simple and attractive food delivery interface where users can:

- Sign in through the login page
- Explore popular food items
- Browse South Indian, Non-Veg and Mandi categories
- Search for food items
- Filter food based on categories
- Add food items to the cart
- View the total cart price
- Simulate placing an order
- Use the website on desktop and mobile screens

🛒 Cart Functionality

The cart functionality is implemented using JavaScript and browser localStorage.

When a user adds a food item to the cart, the food name and price are stored locally in the browser.

The cart then calculates and displays the total price.

 📱 Responsive Design

The website is designed to work on:

- Desktop
- Tablet
- Mobile

CSS media queries are used to adjust the layout according to different screen sizes.

 ⚠️ Project Scope

FoodVerse is currently a frontend prototype.

It does not include:

- Backend server
- Database
- Real user authentication
- Online payment
- Real-time order tracking
- Live restaurant data

The login, cart and order placement are implemented as frontend demonstrations.
